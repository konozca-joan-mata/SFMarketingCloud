# Salesforce Marketing Cloud Knowledge Hub

Este repositorio contiene una guía interactiva y estructurada para el dominio de **Salesforce Marketing Cloud Engagement**. A diferencia de una guía de certificación pura, este recurso está diseñado para el **trabajo diario y la formación profesional**, cubriendo desde la configuración inicial hasta integraciones avanzadas y estrategias omnicanal.

## 🚀 Cómo Empezar
Para navegar por la guía, abre el archivo principal en tu navegador:
👉 **[START.html](./START.html)**

---

## 📂 Estructura de Contenidos

### 1. Fundamentos y Configuración
- **Carpeta:** `/1_Fundamentos`
- **Temas:** Configuración de cuenta (Setup), roles y responsabilidades del equipo, seguridad (MFA), entregabilidad (IP Warming) y cumplimiento legal (GDPR/CCPA).

### 2. Gestión de Datos & Contactos
- **Carpeta:** `/2_Gestion_Datos`
- **Temas:** Uso avanzado de Contact Builder, Data Designer, segmentación de audiencias, Data Extensions y políticas de eliminación de contactos.

### 3. Contenido & Email Studio
- **Carpeta:** `/3_Contenido_Email`
- **Temas:** Estrategias de Content Builder, contenido dinámico, formularios interactivos y personalización impulsada por IA con Einstein.

### 4. Automatización & Journeys
- **Carpeta:** `/4_Automatizacion_Journeys`
- **Temas:** Diseño de trayectorias 1:1 con Journey Builder y procesamiento de datos en lote con Automation Studio.

### 5. Omnicanalidad Avanzada
- **Carpeta:** `/5_Omnicanal_Avanzado`
- **Temas:** Mensajería móvil (MobileConnect/SMS), WhatsApp y publicidad digital basada en datos con Advertising Studio.

### 6. Desarrollo & AMPscript
- **Carpeta:** `/6_Desarrollo_AMPscript`
- **Temas:** Guía técnica de AMPscript, Server-Side JS (SSJS), APIs y herramientas para desarrolladores.

### 7. Ecosistema & Data Cloud
- **Carpeta:** `/7_Ecosistema_DataCloud`
- **Temas:** Marketing Cloud Connect (CRM), Inteligencia de datos con Datorama y la unificación de identidad en Data Cloud (CDP).

## 🎨 Diseño y Tecnología
- **UI/UX:** Basado en un sistema de diseño moderno con glassmorfismo y gradientes.
- **Frontend:** HTML5 semántico y CSS3 personalizado (`marketing_style.css`).
- **Fuentes:** Outfit (vía Google Fonts).
